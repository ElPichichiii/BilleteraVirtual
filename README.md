# Billetera Virtual

Este proyecto es una aplicación de Billetera Virtual desarrollada en C# (.NET) para gestionar cuentas, movimientos y transferencias de dinero de manera segura.

##  Documentación del Sistema

Toda la documentación técnica del modelado de dominio se encuentra en el directorio [`docs/`](./docs/):

* **[Modelo de Dominio y Secuencia](./docs/modelo.md):** Contiene el Diagrama de Clases UML (agregación, composición y jerarquía de operaciones) y el Diagrama de Secuencia del flujo de transferencias con sus validaciones en sintaxis Mermaid.

##  Tecnologías Utilizadas

* **Lenguaje:** C# / .NET
* **Modelado:** Mermaid.js (renderizado nativo en GitHub)
* **Control de versiones:** Git & GitHub
